# Postprocess OWI Files

This folder contains Bash scripts used to:

1. Remove duplicate yearly OWI headers.
2. Concatenate yearly OWI files.
3. Produce a continuous multi-decadal forcing record.

Final output:

era5_StartYear/date_EndYear/date_formatOWI_Basin.pre

era5_StartYear/date_EndYear/date_formatOWI_Basin.win
